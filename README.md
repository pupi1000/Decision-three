Micro App interactiva para el modelado, resolución y visualización de árboles de decisión bajo incertidumbre, análisis de sensibilidad y actualización de probabilidades mediante el Teorema de Bayes.

## 🚀 Requisitos e Instalación

La aplicación es completamente autónoma (Vanilla HTML/CSS/JavaScript) y no requiere instalación de dependencias, servidores locales ni conexión obligatoria a internet.
